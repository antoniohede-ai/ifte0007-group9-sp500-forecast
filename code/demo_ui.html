What is preset, what is live

Preset The tool menu and its code; the goal, the brief's rules and the narration format; in /whatif, the change chosen by the presenter.

Live The agent's plan, which tools it calls and in what order, the what-if values it picks, every word and its reasoning, whether it catches the hidden fault, and its recommendation.

Network · pulled now The fetch tool downloads the public data at that moment (Yahoo, Cboe) from a fixed list of sources. Nothing is preset about the numbers.

Python Every other tool result is computed at that moment from the data just pulled.
